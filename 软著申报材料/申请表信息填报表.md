## 六、软件功能与技术特点（填表时整段粘贴）

本软件是一款面向科研诚信建设与 AIGC 可信溯源的多人实时协同写作系统。软件基于
Yjs 无冲突复制数据类型（CRDT）实现多端实时协同编辑，支持多光标互见与 AI/人类
作者内容着色区分；集成文献检索、论文写作、学术规范审查三类智能体（Agent），
实现从文献调研到论文起草再到导师审稿的一体化科研辅助流程，文献检索支持 arXiv
实时检索与本地文献库自动降级；内置基于 Kirchenbauer 绿名单水印算法（KGW）的
AIGC 水印检测引擎，可对整篇文档或任意文本进行 AI 生成内容检测并给出置信度；
建立基于 SHA-256 哈希链的版权溯源机制，对每一次编辑操作生成不可篡改的操作日志，
任一历史记录被修改即整链校验失败；支持文献关键词检索、GB/T 7714 标准引文一键
生成与插入；支持导出含溯源元数据的 Markdown 文件。软件采用前后端分离架构，
后端基于 Python FastAPI 与 SQLAlchemy 异步框架，数据库支持 PostgreSQL 与 SQLite
自动回退；前端基于 React 18、TypeScript、Vite 与 Tiptap 编辑器；WebSocket 协同
通道采用纯转发模式，服务端无状态，扩展性好。软件适用于高校科研团队论文协同撰写、
期刊编辑部审稿以及需要对 AI 生成内容进行检测和编辑历史审计的一般写作场景。
