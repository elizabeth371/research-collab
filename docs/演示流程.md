# 智溯 · GUI 演示流程（人工操作剧本）

> 面向评审/答辩的界面演示脚本。每个步骤给出**操作**与**预期结果**，
> 全程约 8-10 分钟。前置：本地或 Docker 已部署（见 `docs/DEPLOYMENT.md`），
> 打开 `http://localhost`（Docker）或 `http://localhost:5173`（本地开发）。

---

## 演示一：协同编辑与多光标（2 分钟）

1. 打开两个浏览器标签页（或窗口），登录同一账号，打开同一文档
   （如「演示文档 · 多Agent协同科研编辑」）。
2. **操作**：在标签页 A 中选中一段文字并修改。
   **预期**：标签页 B 实时同步；两人光标以不同颜色并存（awareness 多光标）。
3. **操作**：点击「+ 新建文档」创建新文档，切回原文档。
   **预期**：文档切换正常，编辑器内容随所选文档切换。

## 演示二：Agent 编排 + AI 写稿水印注入（2 分钟）

1. 打开左侧 Agent 面板，选择「写稿人（Writer）」。
2. **操作**：输入写作指令（如"写一段关于 AI 水印保障科研诚信的简介"），
   点击触发。
   **预期**：多 Agent 消息流按 调研 → 写作 → 审稿 顺序出现在面板；
   最终稿件以**蓝色 AI 标记**插入编辑器。
3. **操作**：选中一段 AI 生成的蓝色文字 → 出现气泡菜单 → 点「润色」。
   **预期**：文字被替换为润色版本（仍为蓝色 AI 标记），并提示优化处数。

## 演示三：水印检测与每文档密钥（2 分钟）

1. 打开右侧「水印检测」面板，确认当前文档为测试样例（含水印）。
2. **操作**：点击「检测当前文档全文并留痕」。
   **预期**：判定「AI 生成 (含水印)」，z 统计量 > 4（约 8-9），
   置信度接近 100%；底部检测历史新增一条记录。
3. **操作**：切换到「演示文档」再检测。
   **预期**：判定「人类创作」（z ≈ 2.5，低于阈值 4.0，不误判）。
4. 回到「文档水印参数」区块：拖动 γ/δ 滑块 →「保存参数并留痕」。
   **预期**：显示"已保存…写入溯源链"；「显示密钥」可查看 64 位密钥 hex
   与指纹；「重新生成密钥」后指纹变更（旧密钥水印不可再检出，界面有警告）。

## 演示四：溯源链（1 分钟）

1. 打开右侧「溯源链」面板。
   **预期**：按时间正序列出全部操作（插入/删除/替换/AI 生成/水印检测/
   水印参数），每条带哈希值；顶部「校验哈希链」显示 ✅ 完整（valid=true，
   逐条校验通过）。
2. 亮点话术：*"每次编辑都写入 SHA-256 哈希链，链尾哈希由前一条哈希递推，
   任何人篡改任意一条日志，整条链校验立即失败——这就是版权证据链。"*

## 演示五：对抗鲁棒性实验（1 分钟）

1. 打开「水印检测」面板 →「水印对抗鲁棒性实验」区块。
2. **操作**：点击「对当前文档全文运行攻击矩阵」（勾选"机器翻译回译"可选）。
   **预期**：生成攻击矩阵表——随机删除 10%/30%、截断 20%、同义替换、
   噪声、局部乱序各攻击后的 z 值与判定。讲解：*"删除 30% 字符后 z 仍有
   5.0 可检出；局部乱序（窗口 4）会把 z 打到 0.6 检出失败——说明水印
   对重排攻击脆弱，这是方案的真实边界，也写进了实验报告。"*

## 演示六：版权证据包导出（1 分钟）

1. 打开「水印检测」面板 →「📦 版权证据包导出」。
2. **操作**：依次点击 PDF / Markdown / JSON。
   **预期**：浏览器下载 `evidence-*.pdf` 等文件；PDF 包含八大章节
   （文档信息、水印参数与密钥指纹、检测历史、溯源链、哈希链校验、
   导出时刻实时检测、全文快照、package_hash）。
3. 亮点话术：*"证据包自带 package_hash，接收方把字段重新排序序列化后
   重算 SHA-256，与包内哈希一致即证明文件未被篡改，可作为版权审计材料
   存档或提交。"*

## 一键自动化演示（备选）

若需快速走查而非人工操作，可运行：

```bash
bash scripts/demo.sh http://localhost:8000
```

该脚本自动完成健康检查、文档列表、正/负样本检测、参数与指纹、溯源链
校验、攻击矩阵、三格式证据包导出与哈希校验，输出 10 项检查结果。
