## 2. 项目背景与痛点（1-2 页）
- 政策背景：GB 45438-2025《人工智能生成合成内容标识方法》+《标识办法》2025.9.1 施行——AIGC 显式/隐式标识成为**法定合规义务**（引用申报书研究现状）
- 三大痛点（每点配一张示意图/数据）：
  1. 高生师比 17.14:1 → 指导反馈滞后、反馈真空期长
  2. 多人跨时空协同：编辑冲突、版本混乱、AI 工具与写作环境割裂
  3. AI 生成内容无标记、多人修改后溯源断链、人机贡献边界模糊

## 3. 国内外研究现状与切入点（1-2 页）
- 三大领域现状一句话概括：多智能体（MetaGPT 角色化协同）、实时协同（CRDTs/Yjs）、文本水印（Kirchenbauer 等静态嵌入范式）
- **核心切入点**：三大领域割裂，现有水印均为"静态嵌入-事后检测"，未适配科研写作"多人多轮迭代修订"；本项目做**一体化整合 + 动态溯源**

## 4. 创新点（1 页，配架构图）
1. **三元角色化多智能体**：调研/写稿/导师审稿 Agent，LangGraph SOP 编排，人机共研
2. **CRDT 实时协同 + AI 无缝嵌入**：AI 产出以蓝色标记直接写入协同画布，进同一条溯源链
3. **生成式同步水印 + 哈希链**：生成即标记（Kirchenbauer 绿名单 + logprobs 重采样）、修改可追溯、权属可界定；每文档独立密钥
4. **一体化可信工作台**：协同 + Agent + 水印溯源 + 文献 + 聊天 + 版本权限一站式

## 5. 技术路线与系统架构（1-2 页）
- 分层架构图（复用申报书图 4 风格）：用户层 / 协同编辑层 / 多智能体服务层 / 核心引擎层（水印、溯源链）/ 基础数据层
- 技术栈：React 18 + Tiptap + Yjs + y-websocket ｜ FastAPI + SQLAlchemy(async) + SQLite/PG ｜ LangGraph + DeepSeek-V3 ｜ reportlab 证据包
- 部署：Docker Compose 一键部署，SQLite 数据卷持久化

## 7. 实验结果与技术指标（1-2 页，表格为主）
| 指标 | 数值 |
|---|---|
| 水印检出 z 值（LLM 生成，校准参数） | 6.7 – 12.7（阈值 4.0） |
| 含水印文档检测 | z≈8.9、置信度 100% |
