## J. 并发写入与溯源链完整性（缺陷 D1 修复回归）

> 背景：《AI测试验收报告_20260820》发现缺陷 D1——同一文档并发写入（多 Agent 写作 /
> 水印检测 / 正文保存重叠）时，多个请求读到相同链尾 `prev_hash`，在同一秒内算出相同
> `current_hash`，违反 `op_logs.current_hash` 的 UNIQUE 约束，导致 500 且溯源链断裂。
> 修复：按文档粒度 `asyncio.Lock` 串行化"读链尾 → 追加日志 → 提交"全过程。
> 以下用例验证修复后并发写入零 500、日志零丢失、哈希链仍完整。

### TC-26 并发写入自动化回归（pytest 单用例）
- **步骤**：
  ```bash
  cd backend
  python -m pytest tests/test_api_integration.py::test_concurrent_writes_no_500_and_chain_valid -q
  ```
- **输入**：用例内部对同一文档并发发起 2 次内容 PATCH + 2 次全文水印检测。

## 附录三：实时并发压测脚本（缺陷 D1 修复验证，TC-27/TC-28）

```python
# 保存为 live_concurrency_test.py, 后端启动后执行: python live_concurrency_test.py
# 依赖: pip install httpx
import asyncio
import httpx

BASE = "http://localhost:8000"
DEMO_USER = "00000000-0000-4000-8000-000000000001"
N = 20  # 并发请求数 (PATCH 与全文水印检测交替, 各一半)


async def main():
    async with httpx.AsyncClient(timeout=60) as c:
        # 1) 新建独立压测文档 (POST 不写 op_log, 链为空)
        r = await c.post(f"{BASE}/api/documents", json={
            "title": "并发压测文档-D1回归", "owner_id": DEMO_USER, "content": "",
        })
        assert r.status_code == 201, r.text
        doc_id = r.json()["id"]
        print("压测文档:", doc_id)

        # 2) N 个并发混合请求: 偶数位 PATCH, 奇数位水印检测
        async def do_patch(i: int):
            return await c.patch(f"{BASE}/api/documents/{doc_id}", json={
                "content": f"并发写入正文内容-{i}。", "operator_id": DEMO_USER})

        async def do_detect():
            return await c.post(f"{BASE}/api/watermark/documents/{doc_id}/detect")

        tasks = [do_patch(i) if i % 2 == 0 else do_detect() for i in range(N)]
        results = await asyncio.gather(*tasks, return_exceptions=True)

        exceptions = [x for x in results if isinstance(x, Exception)]
        bad = [x.status_code for x in results
               if not isinstance(x, Exception) and x.status_code >= 400]
        print(f"异常: {len(exceptions)} | 4xx/5xx: {bad}")

        # 3) 校验: 日志恰好 N 条 (零丢失), 哈希链完整
        logs = (await c.get(
            f"{BASE}/api/watermark/documents/{doc_id}/provenance")).json()
        verify = (await c.get(
            f"{BASE}/api/watermark/documents/{doc_id}/provenance/verify")).json()
        print(f"日志: {len(logs)} (期望 {N}) | verify: {verify}")

        ok = (not exceptions and not bad
              and len(logs) == N
              and verify.get("valid") is True
              and verify.get("checked") == N)
        print("LIVE_CONCURRENCY_RESULT:", "PASS" if ok else "FAIL")


asyncio.run(main())
```
