# 演示视频分镜脚本（结题答辩用）

> 时长：约 8-10 分钟 ｜ 工具：任意录屏软件（OBS / Bandicam / Windows 录屏）
> 环境：已部署系统（本地 `localhost:5173` 或 Docker `localhost`），分辨率建议 1600×950
> 每个分镜给出：画面 / 操作 / 讲解词（可直接照读）/ 对应素材截图（`test-harness/screenshots/s16-*.png`）
> 自动化演示：`bash scripts/demo.sh http://localhost:8000`（10 项检查自动走查）

---

## 第 1 幕：开场与项目定位（约 40 秒）

- **画面**：系统主界面全貌（三栏布局）
- **素材**：`s16-01-编辑器主界面.png`
- **操作**：打开系统，停留在演示文档
- **讲解词**：
  > 各位评委老师好，我们带来的作品是「智溯——面向高校科研写作场景的多智能体协同编辑与 AIGC 内容溯源原型系统」。
  > 它针对高校科研写作中**协作效率低、指导反馈慢、AI 内容溯源难**三大痛点，把多智能体协同、实时协同编辑和文本水印溯源整合到同一块科研画布上。
  > 系统由长安大学人工智能专业本科生团队独立开发，前后端代码全部开源在 GitHub。

## 第 2 幕：多人实时协同编辑（约 1 分钟）

- **画面**：双窗口 / 双标签页同开一个文档，演示多光标与实时同步
- **操作**：打开两个浏览器标签页，在页 A 输入文字，页 B 实时显示；光标以不同颜色并存
- **讲解词**：
  > 底层采用 CRDT 无冲突复制数据类型与 WebSocket 长连接。大家可以看到，两个窗口同时编辑同一个文档，**输入即同步**，没有保存按钮、没有冲突覆盖。
  > 这背后是 Yjs 协同引擎与自研的纯转发协同服务，多光标与在线状态实时可见，把"事后批改"升级为"实时共研"。

## 第 3 幕：多智能体写作辅助（约 1.5 分钟）

- **画面**：左侧 Agent 面板；触发调研/写稿/审稿
- **素材**：`s16-02-Agent群聊.png`、`s16-03-审稿红牌黄牌.png`
- **操作**：向 Agent 群聊下发指令（如"调研 AI 文本水印技术并撰写引言"）；展示三个 Agent 依次发言；随后点击「开始审稿」展示红牌/黄牌卡片
- **讲解词**：
  > 左侧是借鉴 MetaGPT 思想构建的**调研、写稿、导师审稿三元 Agent 团队**，用 LangGraph 编排标准作业流程。
  > 大家看到，一条指令下发后，调研 Agent 检索文献、写稿 Agent 生成稿件（以**蓝色 AI 标记**直接写入文档）、导师审稿 Agent 给出红牌/黄牌分级意见，并支持一键润色段落。
  > 这一设计回应了高生师比下"导师指导反馈滞后"的真实痛点。

## 第 4 幕：AIGC 水印注入与检测（约 1.5 分钟）

- **画面**：右侧水印面板；AI 写作水印注入演示 + 全文检测结果
- **素材**：`s16-04-水印生成自检.png`、`s16-05-全文检测结果.png`、`s16-13-文档水印参数.png`
- **操作**：点击「生成带水印文本并自检」→ 展示 z 统计量与「已注入水印」徽章 → 插入文档 → 「检测当前文档全文并留痕」→ 展示判定与置信度；再展示每文档独立密钥与指纹
- **讲解词**：
  > 这是系统的核心技术——**生成阶段同步嵌入的隐形水印**。系统在调用 DeepSeek 生成文本时，通过 logprobs 重采样把 Kirchenbauer 绿名单逻辑水印嵌入解码过程，**生成即标记**。
  > 检测端用 z 统计量判定，阈值 4.0。大家看，含水印文本 z 值达到 8 以上、置信度接近 100%；而纯人类创作的文档不会被误判。
  > 每个文档还有**独立的水印密钥**，指纹可查、密钥可重建，即使文档之间也不互相污染。

## 第 5 幕：版权溯源链与证据包（约 1.5 分钟）

- **画面**：溯源链面板；证据包导出
- **素材**：`s16-06-溯源链.png`、`s16-08-证据包导出.png`
- **操作**：展示溯源链全部操作日志与哈希校验结果（✅ 完整）；导出 PDF / Markdown / JSON 证据包并展示 package_hash
- **讲解词**：
  > 每一次编辑、生成、检测、参数变更，都会写入一条 **SHA-256 哈希链日志**——每条日志的哈希由前一条递推，链尾与链首环环相扣。
  > 任何人篡改任意一条记录，整条链的校验立刻失败，实现**不可篡改**的过程留痕。
  > 我们还提供**版权证据包导出**：把文档全文、水印参数与密钥指纹、检测历史、溯源链与校验结果打包为 PDF/Markdown/JSON，附 SHA-256 完整性哈希，可作为版权审计材料直接提交。

## 第 6 幕：对抗鲁棒性与版本权限（约 1.5 分钟）

- **画面**：鲁棒性攻击矩阵表；文档设置弹窗
- **素材**：`s16-07-鲁棒性攻击矩阵.png`、`s16-09-版本回溯.png`、`s16-10-权限管理.png`
- **操作**：对带水印全文运行 6 类攻击矩阵，展示各攻击后的 z 值衰减与判定；打开「文档设置」展示版本回溯列表并恢复一个历史版本；切换权限管理展示协作模式/导出策略
- **讲解词**：
  > 针对"水印会被修改破坏"的质疑，我们做了完整的对抗实验：随机删除 30% 字符后 z 值仍有 5.0 可检出；同义替换、插入噪声几乎不影响判定。实验结论——**14 项攻击组合整体检出率 78.6%，排除局部乱序后达 91.7%**，该边界也如实写进了实验报告。
  > 此外系统支持**版本回溯**（自动快照、一键恢复、恢复留痕）和**文档级权限管理**（协作模式、水印策略、导出策略、协作者名单），导出策略为"禁止"时前后端双重拦截。

## 第 7 幕：协作聊天与总结（约 1 分钟）

- **画面**：协作聊天面板；主界面全景收尾
- **素材**：`s16-11-协作聊天.png`、`s16-12-文献检索.png`
- **操作**：在协作聊天中发一条消息（双标签页演示实时送达）；切到文献检索展示检索与引用
- **讲解词**：
  > 系统还内置同文档房间的**实时协作聊天**，讨论过程同样可回溯；文献检索面板对接学术语料，可一键插入参考文献。
  > 整个系统已完成 **144 项自动化测试**与 8 组真实浏览器验收，支持 Docker 一键部署。
  > 我们相信，智溯为"AI 辅助科研写作的规范化、透明化"提供了一套可落地的技术方案。谢谢各位老师！
