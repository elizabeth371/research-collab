# 软件著作权申请材料清单

> 系统名称建议：**智溯 · 多智能体科研协同编辑与版权溯源系统 V1.0**
> 依据：申报书经费预算含「软件著作权登记费」。以下为软著登记所需材料清单（以中国版权保护中心现行要求为准，提交前请复核官网最新模板）。

---

## 一、必交材料

| # | 材料 | 说明 | 来源 |
|---|------|------|------|
| 1 | 计算机软件著作权登记申请表 | 版权保护中心官网在线填写后打印（含软件全称、简称、版本号、开发完成日期、首次发表日期） | 官网申请 |
| 2 | 软件说明书（含操作手册） | 图文并茂介绍软件功能与操作流程，**建议 15-30 页**，截图必须清晰 | 本文档第三节 + 截图集 |
| 3 | 源代码文档 | 前后端核心代码各取**前 30 页 + 后 30 页**（每页不少于 50 行），共约 3000 行 | 见本文档第二节 |
| 4 | 身份证明 | 在校学生：身份证 + 学生证；以学校名义申请需加盖学校公章（大创项目通常以**学校或团队**名义登记，先确认） | 准备 |

## 二、源代码提交清单（按前 30 页 + 后 30 页规则抽取）

建议提交以下核心模块代码（共 60 页以内，页眉标注模块名与页码）：

| 模块 | 建议抽取文件 | 定位 |
|---|---|---|
| 水印引擎 | `backend/services/watermark_engine.py`（绿名单/重采样/检测） | 核心技术 |

| 哈希链溯源 | `backend/services/oplog_chain.py` | 溯源核心 |
| 文档/版本/权限 API | `backend/api/documents.py` | 业务核心 |

| 聊天服务 | `backend/websocket/chat_ws.py` | 功能模块 |

> 抽取规则：连续 60 页以内源代码，前后各 30 页；如总代码不足 60 页则全量提交。
> 注意：提交代码需与说明书功能一致，可删除注释中的敏感信息（如 API Key 一律不得出现——`.env` 不入库，代码中无明文密钥，已确认）。

## 三、软件说明书结构建议（15-30 页）

1. 软件概述（名称、版本、运行环境、功能简介）
2. 开发与运行环境（前端 Node/React、后端 Python/FastAPI、浏览器 Chrome/Edge）
3. 安装与部署（本地 + Docker 两种方式，引用 `docs/DEPLOYMENT.md`）
4. 功能操作说明（每个功能配截图 + 操作步骤）：
   - 文档管理与实时协同编辑（多光标/批注）
   - 多 Agent 群聊与写稿/审稿/润色
   - AI 写作水印注入与全文检测（z 值/置信度）
   - 溯源链查看与哈希校验
   - 鲁棒性攻击矩阵实验
   - 版权证据包导出（PDF/MD/JSON）
   - 文档设置：版本回溯与权限管理
   - 协作聊天与文献检索
5. 附录：主要技术指标表

## 五、注意事项

- **命名一致性**：申请表、说明书、源代码文档中的软件名称与版本号必须完全一致
- **著作权人**：大创项目一般登记为学校或团队负责人名下，先与指导教师确认归属
- **表格下载**：中国版权保护中心（www.ccopyright.com.cn）在线填报
- **时间**：软著登记周期约 30-60 个工作日，建议结题答辩前 3 个月提交（与申报书 2027.3-6 结题节奏匹配，现在提交正合适）
