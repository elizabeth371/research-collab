# 水印对抗鲁棒性实验报告（步骤 11）

> 项目：智溯 · 多智能体科研协同编辑与版权溯源系统
> 日期：2026-08-26 ｜ 引擎：Kirchenbauer 绿名单字符级水印（DeepSeek logprobs 重采样注入）

## 1. 实验目的

验证字符级 Kirchenbauer 水印在常见内容攻击下的检出鲁棒性，为论文提供实验数据。
攻击矩阵覆盖论文/报告中常见的二次编辑场景：

| 攻击 | 模拟场景 | 强度 |
| --- | --- | --- |
| 随机删除 10% / 30% 字符 | 内容删改、压缩 | 中 / 强 |
| 截断末尾 20% | 只引用文章开头部分 | 中 |
| 中文同义替换 | 人工改写润色 | 强 |
| 插入噪声字符 | 排版噪声、乱码 | 弱 |
| 局部窗口乱序（窗口 4） | 错字、语序扰动 | 强 |
| 机器翻译回译 zh→en→zh | 跨语言改写（真实 DeepSeek） | 最强 |

## 2. 实验设置

- **水印注入**：真实 DeepSeek `deepseek-chat`，temperature=1.5，逐位置 top-20 logprobs 本地绿名单重采样（delta=4.0），字符级 bigram 绿名单，γ=0.5。
- **检测**：同一 `detect_watermark` 解码，z 统计量阈值 z>4.0 判为 AI 生成（Kirchenbauer 原文标准）。
- **样本**：两段独立 prompt 生成的真实中文文本（384 字 / 473 字），均为注入后立即自检 z>13。
- **确定性**：所有攻击算子带固定 seed，实验可复现。

## 4. 结论与讨论

1. **内容删改鲁棒**：随机删除 30% 字符后 z 仍 >8（检出余量充足），同义改写、噪声插入、截断几乎不衰减检测能力。字符级水印的冗余性使其对"内容压缩/改写"类攻击高度鲁棒。
2. **局部乱序是弱点的必然性**：字符级 bigram 水印依赖相邻字符的绿名单关系，窗口乱序直接破坏该关系（样本 A z=2.01、样本 B z=2.65 均跌至人类水平）。这是字符级水印的已知理论边界（与 Kirchenbauer 原文对 token 级水印的讨论一致）。
3. **机器翻译回译介于中间**：样本 A 未检出（z=2.85），样本 B 临界检出（z=4.70）——回译后的中文措辞保留了部分原相邻字符对。跨语言改写对字符级水印构成威胁，但非完全免疫。
4. **总体检出率 11/14（78.6%）**：若排除"局部乱序"这一已知理论弱项，常规编辑攻击下检出率 11/12（91.7%）。

**论文写作建议**：本实验既呈现了水印的强鲁棒性（删除/改写/噪声），也如实报告了字符级方案的边界（乱序/翻译），并可作为后续工作引入语义级水印（如段落级统计签名）的动机。
