# 长安大学 大创项目结题验收要求速查

> 整理时间：2026-08-20
> 依据：长安大学教务处及公路学院、土地工程学院、地球科学与资源学院等学院官网
> 公开发布的《大学生创新创业训练计划项目结题验收通知》（2019-2025 多届），
> 各学院要求大体一致，以你所在学院当年通知为准。

---

## 一、结题验收材料清单（创新训练项目）

| 材料 | 说明 |
|------|------|
| 结题报告书 | 按学校模板撰写，含：研究过程、财务执行情况、成员分工与合作、研究过程日记、主要成绩与收获、不足与展望、论文/专利发表情况等 |
| 研究总结报告 | 一般要求不少于 1 万字（历年通知口径，具体按当年模板） |
| 项目过程记录册 | 在中期检查基础上完善 |
| 大创项目结题简表 | 按模板填写 |
| 支撑材料 | 研发实物、发表的论文、**设计或专利证明（软件著作权证书属于此类）**、获奖证书等 |

> 报送流程：项目组撰写材料（Word 版，用学校模板）→ 提交**指导老师审核** →
> 在「智慧云创大创项目管理系统」提交结题验收申请 → 指导老师在系统内审核确认。

## 二、验收形式

- 项目负责人现场答辩 + 专家评议；
- **PPT 汇报不超过 8 分钟**（汇报内容：开展的工作、财务执行、是否按计划完成、所获成果、特色与创新点、存在问题）；
- 项目组全体人员需提前到场；纸质材料在汇报前交评委查阅。

## 三、软著在结题中的定位

- 软件著作权登记证书 = **知识产权类支撑材料/成果**（与论文、专利并列）；
- 官方通知明确支撑材料含"研发的实物、发表的相关的论文、设计或专利证明等"，
  软件著作权证书（或受理回执）可作结题成果附件；
- 结题报告书中"发表论文和获得专利情况"一栏可填写软著申请/授权情况。

## 四、知识产权归属（重要）

- 公开的结题验收通知中**未直接规定**大创项目成果的知识产权归属；
- 归属一般由《大创项目任务书/立项合同》的条款决定——**请翻看立项时签的合同**，
  重点找"成果归属/知识产权"条款；
- 若合同无约定，通常按"谁开发谁拥有"处理，但需与指导老师确认学校政策；
- **未确认权属前，不要以个人名义提交软著申请。**

## 五、给指导老师的沟通建议

见《软著申报材料/申请表信息填报表.md》中的话术，核心确认两点：
1. 以个人名义申请软著，学校对成果权属是否有要求；
2. 结题是否需要成果备案等流程。
